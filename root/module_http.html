HTTP 主从状态机

Master-Slave State Machine & Elastic Buffer

当客户端发出 HTTP 请求时，Web 服务器接收到的是连续不断的字节流。如何在非阻塞的 I/O 环境下，精准切割、解析并响应这些错综复杂的报文，是服务器性能的“阿喀琉斯之踵”。

本模块采用高效的 主从状态机（Master-Slave State Machine） 架构，并针对底层内存管理进行了彻底革新：

  • 主从解耦的状态机： 从状态机（Slave）负责底层读取，逐个字符分析，精准定位 \r\n 行结束符；主状态机（Master）负责宏观业务，依次推进解析请求行（Request Line）、请求头（Headers）和请求体（Body），逻辑清晰且杜绝阻塞。
  • 分散/聚集 I/O (writev)： 响应阶段，HTTP 头与静态资源文件物理内存分离。系统调用 writev 将内存中分散的数据块一次性汇聚发送，免去了在用户态拼接大型字符串的开销。
  • mmap 零拷贝技术： 对请求访问的静态文件（如 HTML、图片），直接通过 mmap 映射到进程虚拟内存。绕过传统的 read/write 内核空间多次拷贝，极大提升了静态资源的吐出速率。

Epoll 事件路由机制

I/O Multiplexing & Unified Event Source

在面对海量客户端同时在线时，传统的 select 或 poll 模型因轮询遍历带来的性能损耗而显得力不从心。要想跨越 C10K 门槛，服务器必须具备极其敏锐的“事件雷达”。

本系统网络层全面拥抱了 Linux 平台最高效的 Epoll 多路复用技术，构建了一套零延迟、高吞吐的事件路由枢纽：

  • 红黑树与双向链表引擎： Epoll 在内核态使用红黑树管理数十万计的监听套接字（fd），并通过回调机制将就绪事件推入双向链表，实现了 epoll_wait 接近 O(1) 的超高事件分发效率。
  • ET (边缘触发) 高速模式： 相比 LT（水平触发），系统将读写套接字配置为更狂暴的 ET 模式配合非阻塞 I/O。状态机仅在数据状态跳变的瞬间被唤醒，最大程度减少了内核态与用户态的上下文切换，压榨系统极限性能。
  • EPOLLONESHOT 线程安全保障： 针对同一个 Socket 可能会被并发触发的问题，系统为所有连接注册了 EPOLLONESHOT 事件，确保任一时刻仅有一个工作线程操作该请求，从源头上斩断了线程安全隐患。
  • 统一事件源设计： 通过 socketpair 创建全双工管道，巧妙地将系统异步信号（如 SIGALRM 心跳、SIGTERM 终止）转化为可读事件，无缝并入 Epoll 监听矩阵，实现了网络 I/O 与系统信号处理的完美统一。

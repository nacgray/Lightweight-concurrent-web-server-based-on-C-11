最小堆定时器

Min-Heap Timer Management Module

在网络并发编程中，服务器必须具备及时剔除“非活跃连接（死连接）”的能力，以防止系统套接字资源被恶意耗尽。原版项目采用 双向升序链表，其 O(N) 的时间复杂度在应对高频并发时会引发严重的 CPU 算力浪费。

本模块经过彻底重构，引入了基于完全二叉树的 最小堆（Min-Heap） 结构，完成了跨越式的性能升级：

  • O(log N) 极速调整： 无论是新连接插入（sift_up）还是活跃连接续期（sift_down），操作复杂度均被压榨至对数级别。即使在千万级并发下，调整一次定时器也仅需极少的比较操作。
  • O(1) 精准心跳检测： 最小堆的堆顶永远是“最早过期的连接”。每次触发 SIGALRM 心跳时，只需检查数组首元素（front），若未超时，则直接返回，避免了无意义的遍历。
  • 哈希映射消除遍历： 引入 std::unordered_map 建立 File Descriptor (fd) 到堆数组索引的直接映射，实现了真正的 O(1) 节点定位。
  • Modern C++ 闭包回调： 摒弃了传统的 void* 万能指针与繁杂的 client_data 结构体，采用 std::function 与 std::bind 将任务执行流与当前连接参数优雅封装。

高性能异步日志系统

Asynchronous Logging & Block Queue

在极高并发的网络服务中，频繁的磁盘读写（如直接调用 fprintf 或 fwrite）会导致工作线程被内核 I/O 队列严重阻塞，成为拉低整体服务器 QPS（每秒查询率）的致命隐患。

为此，本系统实现了一套基于生产者-消费者模型的 全异步日志管理系统，确保业务逻辑的飞速运转不受磁盘写操作拖累：

  • 懒汉单例与双模式架构： 日志模块采用 C++11 局部静态变量实现线程安全的懒汉单例模式。系统支持同步/异步双模式无缝切换：低并发下直接写盘，高压态下自动启用异步缓冲写入。
  • 线程安全阻塞队列： 核心使用 std::mutex 与条件变量（或信号量）构建了 block_queue。工作线程仅需极微小的开销将日志字符串推入队列，专属的后台写线程会平滑地将其批量刷入磁盘，实现极致的 I/O 解耦。
  • 自动化分表与轮转机制： 系统自带完善的文件管理逻辑。当日期发生跨越，或单文件突破最大行数阈值（如 50000 行）时，会自动切分并创建带有时间戳的新文件，极大降低了后期运维排查的难度。
  • 变参宏极简封装： 底层利用 vsnprintf 进行高效的内存字符串格式化，上层通过 LOG_INFO、LOG_ERROR 等宏定义对外暴露极简接口，业务层只需像 printf 一样调用即可，优雅且高效。

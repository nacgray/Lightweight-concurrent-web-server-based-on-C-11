数据库连接池与安全模块

DB Connection Pool & SHA-256 Security

在传统的 Web 后端应用中，数据库连接的创建与销毁（TCP 三次握手、MySQL 鉴权等）是极其沉重的 I/O 开销。在高并发场景下，频繁的连接申请会直接压垮数据库引擎。

本系统摒弃了“一请求一连接”的低效模式，设计了全局的 MySQL 连接池，并在用户数据安全方面引入了现代密码学防御体系：

  • 单例模式与池化技术： 系统启动时预先与 MySQL 建立并维护指定数量的 Socket 连接。客户端请求到来时，直接从池中取出空闲连接，用完即还，实现了数据库 I/O 开销的零延迟。
  • RAII 连接管理机制： 结合 C++ 的 RAII（资源获取即初始化）特性，封装了 connectionRAII 类。通过对象的构造与析构，自动完成连接的获取与归还，从根源上杜绝了数据库连接泄漏。
  • 信号量与互斥锁： 采用 C++11 的 std::mutex 与 sem_t 控制并发访问，确保多个工作线程在竞争获取连接时绝对的线程安全。
  • SHA-256 加盐防御加密： 针对原版系统明文存储密码的安全漏洞，重构了鉴权体系。采用 SHA-256 算法，并结合“用户名（动态盐）+ 固定字符串（Pepper）”进行不可逆混合加密，完美抵御彩虹表（Rainbow Table）与拖库攻击。
